# Your paper

Run `npm run dev:paper`. This folder begins with fictional instructional content and
synthetic data; replace them with your manuscript and reproducible exhibits. Keep both
examples for reference throughout development. Read ../../docs/adapt-a-paper.md first.

Set title, authors, abstract and sections under `content/`, configure optional features
in `paper.config.ts`, and register renderers in `exhibits/index.ts`. Replace the fictional
reproduction inputs and code as the scientific exhibits are added. The light-gray design
credit is optional and can be removed from the configuration.

Read [COPYRIGHT.md](COPYRIGHT.md) before importing your manuscript. The starter grants
do not license your real paper; update the paper and reproduction-bundle notices with
the applicable rights holder, manuscript version and journal requirements.
