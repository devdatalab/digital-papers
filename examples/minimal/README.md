# Minimal example

Run `npm run dev` from the repository root. The short fictional paper demonstrates
source-shaped JSON, citations, footnotes, search, collapsible technical text, an interactive
context panel, and a figure/table sharing one reproducible export.

Change `content/` for the paper, `paper.config.ts` for navigation/branding, and `exhibits/`
for scientific renderers. `reproduction/make_all.py` builds every fictional result.
The README at the repository root links the full adaptation workflow and feature index.
