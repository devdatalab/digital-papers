# Nobel feature showcase

Run `npm run dev:nobel` from the repository root. The example preserves selected original
paper content and demonstrates guided scrollytelling, graph toggles, supplementary panels,
intermediate-data explorers, and a reproducible research bundle.

Source omissions are marked. The raw explorer shows five rows, but charts use complete
inputs. Science, Nature and QJE submission pages are templates with permission reminders;
they contain no original correspondence. Recent-laureate updates and errata are removed.

`source/` documents fidelity; `reproduction/exhibits.json` documents generating code.
The example does not maintain or deploy the independent complete publication at
https://nobel-prizes.devdatalab.org/.
